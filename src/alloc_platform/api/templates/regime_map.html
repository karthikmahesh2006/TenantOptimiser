Key Scientific Takeaways

  • When Adaptive Wins: Asymmetric over-declaration where idle capacity exists to be reclaimed for constrained workloads (+11.5 pp to +25.7 pp goodput gain).
  • When Adaptive Underperforms: Uniform honest demand, where dynamic estimation adds solve overhead (2.3 ms), contracts allocations below contractual caps (-31.1% satisfaction), and carries container OOM kill risk (40% OOM rate, -40.0 pp loss).
  • When Adaptive Loses Severely: Heterogeneous multi-resource contention near host saturation (>95% load), where DRF successfully balances dominant shares while 1-D log utility collapses to static weights (-88.9 pp loss).
