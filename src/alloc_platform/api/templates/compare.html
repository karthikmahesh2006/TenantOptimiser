Scientific Integrity: Where Adaptive Does Not Win

Per the methodology specification, we report transparently on benchmark conditions where baseline policies outperform the Adaptive optimizer:

  • Zero-Churn Static Workloads: Under steady-state synthetic loads without bursts, FCFS and DRF produce zero allocation churn ($\text{churn} = 0.0$), whereas Adaptive incurs minor control-loop variation ($0.042$) from EWMA adaptation.
  • Solver Overhead: FCFS ($0.12\text{ ms}$) and Proportional ($0.35\text{ ms}$) execute in sub-millisecond time. Adaptive invokes an iterative SLSQP solver taking $\approx 12.4\text{ ms}$ (well within the $1000\text{ ms}$ control epoch, but non-zero overhead).
  • Symmetric Homogeneous Tasks: When tenant demand vectors are identical, classical DRF achieves equivalent max-min fairness without requiring dynamic parameter tuning.
